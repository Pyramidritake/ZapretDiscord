## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите опцию "Транзит запросов". При ее отключении Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Pyramidritake/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и отметьте "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не нужен

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути

5. Запустите нужный скрипт
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автозапуска: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдется подходящий**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из списка служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - изменить режим обхода для сервисов из `ipset-all.txt`.  
  Это полезно при проверке ресурсов, которые без zapret работают, а с ним - нет.  
  В скобках указано текущее состояние:
    - `none` - ни один IP не участвует в проверке
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** - заменить выбранный фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** - загрузить из репозитория свежую версию `ipset-all.txt`
  - **`Update Hosts File`** - обновить hosts <ins>для исправления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить типичные причины неисправности zapret.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает его работоспособность
  - **`Run Tests`** - открыть проверку стратегий:
    - `Standard tests` - проверить сайты из `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Pyramidritake/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированное содержимое в конец `hosts` или замените аналогичные строки, если они уже были добавлены
  - Сохраните файл и снова проверьте соединение. При проблемах убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если этот способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Pyramidritake/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Стратегия, которая некоторое время помогала, может перестать работать после ее обнаружения.
> В репозитории есть много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из них, изменив ее параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках

- Проверьте наличие адреса ресурса в списках доменов или IP

- Испытайте другие стратегии, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения: [#765](https://github.com/Pyramidritake/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/Pyramidritake/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов, специальных символов и кириллицы
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если выбранная стратегия не помогает, закройте программу через значок замка на панели задач и попробуйте следующую
- После выбора рабочей стратегии включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра или приложение при включенном zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert все еще остается среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите ее следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше все работало.
- См. также [#251](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала определите стратегию, на которой открывается YouTube, и запустите ее
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно использовать ее
- Если браузер тоже не подключается, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/Pyramidritake/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальный вариант:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включенным постоянно: определите все IP игры и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Pyramidritake/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/Pyramidritake/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Списки обхода можно дополнить следующими файлами:
- **`list-general-user.txt`** - домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
