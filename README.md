>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с запретом в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky это параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно настраиваете исключения, предпочтительно добавить исключение; если назначение настройки не вполне понятно, рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (поставщик Cloudflare может быть заблокирован)
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это предпочтительный вариант
    * На роутерах Keenetic включите опцию "Транзит запросов". При её отключении настройка и работа Secure DNS на компьютере могут нарушиться

2. Перейдите на [страницу последнего релиза](https://github.com/Pyramidritake/zapret-discord-youtube/releases/latest) и скачайте архив (zip/rar)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите нужный файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите в **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб (автозапущенной стратегии и WinDivert)
  - **`Game Filter`** — изменение режима обхода для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После смены режима стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние (включено/выключено).
  - **`IPSet Filter`** — изменение режима обхода сервисов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках указано текущее состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена выбранного активного фейка на другой из каталога `bin`
  - **`Update IPSet List`** — получение актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка наличия обновлений
  - **`Run Diagnostics`** — поиск распространённых причин неисправности zapret.  
  В конце можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров (Cloudflare, Amazon и других)


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Pyramidritake/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота
  - С правами администратора откройте текстовым редактором файл `hosts` в созданной папке
  - Вставьте скопированное в конец `hosts` (либо замените ранее добавленный аналогичный фрагмент)
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что `hosts` действительно был сохранён.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Pyramidritake/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Найденный вариант способен работать некоторое время, а затем перестать работать после его обнаружения.
> Здесь собрано много разных стратегий обхода. Если ни одна не подходит, создайте собственную на основе одной из них, изменив её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках

- Проверьте наличие адреса ресурса в доменных или IP-списках

- Попробуйте другие стратегии (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Pyramidritake/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце нажмите Y
- Удалите текущую папку с запретом
- Загрузите свежую версию [со страницы релизов](https://github.com/Pyramidritake/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Щёлкните по архиву ПКМ и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и перейдите к следующей стратегии
- После нахождения рабочего варианта включите автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные для вас ресурсы.

### Античит ругается на WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если прежняя перестала работать.
- См. также [#251](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что выполнена настройка [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Pyramidritake/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Pyramidritake/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и включить `Game Filter`
- если это не дало результата, дополнительно включить `ipset any`

Учитывайте: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема останется, создайте обсуждение в разделе [Discussions](https://github.com/Pyramidritake/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/Pyramidritake/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — исключаемые домены, например когда IP сети присутствует в `ipset-all.txt`, но конкретный домен этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
